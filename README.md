# Practice Workspace

A reusable React + TypeScript + Vite + Tailwind CSS v3 + shadcn-style component playground for practicing real business application problems.

## Included playgrounds

- Expense Tracker
- Analytics Calculator
- Mini CRM
- Quote Builder
- Task Manager
- Customer Data
- Settings
- Dashboard

## Start

```bash
npm install
npm run dev
```

Then open the local Vite URL in your browser.

## Suggested progression

1. Build each feature with local React state.
2. Add localStorage persistence.
3. Add form validation.
4. Add loading/error/empty states.
5. Add Firebase or another backend.
6. Add API integrations.
7. Add tests.
8. Refactor only after the feature works.

## Important

The playgrounds are intentionally mostly empty. The goal is to use this workspace as a coding laboratory rather than a finished template.

## Useful additions later

```bash
npx shadcn@latest add input label textarea select dialog dropdown-menu table tabs badge
```

You can also add React Hook Form, Zod, date-fns and Firebase when a particular exercise needs them.
